# 贵阳数据分析岗能力调研（32 条招聘信息）

**一句话结论：** 数据分析岗的入场券不是 Python，是 **SQL（72%）** 和 **沟通表达（91%）**；贵阳的薪资中位数比上海低 **2.0K**。

## 研究问题

1. 数据分析岗到底要求什么能力？哪些是门槛，哪些是加分？
2. 贵阳和上海的同级岗位，要求与薪资差在哪？

## 数据与方法

| 项 | 内容 |
|---|---|
| 样本量 | **32 条**（贵阳 10 / 上海 22） |
| 来源 | 智联招聘、前程无忧（51job）、应届生求职网 |
| 采集方式 | **半自动采集**：人工复制详情页全文 → 正则解析。平台反爬成本高于收益，故不写爬虫 |
| 采集时间 | 2026-10-27 |
| 处理链路 | 正则解析 → SQLite 入库 → SQL 统计 → 导出 CSV → Pillow 出图 |

### 筛选规则（写在代码里，不是手工挑）

- **保留**：岗位名含 `数据分析 / 商业分析 / 数据运营 / BI`
- **剔除**：含 `标注 / 采集 / 录入 / 销售 / 讲师 / 实施 / 运维 / 开发 / 运营经理`
- **去重**：以「岗位名 + 薪资 + 经验 + 学历」为指纹

原始采集文本全部保留在 `raw/`，脚本每次重新解析，**筛选过程可复现**。

## 结果

| 指标 | 数值 |
|---|---|
| 样本 | 32 条（贵阳 10 / 上海 22） |
| SQL 提及率 | **71.9%** |
| 沟通表达提及率 | **90.6%** |
| BI 可视化 / 统计分析 | 53.1% / 56.2% |
| Python / Excel | 50.0% / 46.9% |
| 建模算法 | 40.0% |
| 贵阳薪资中位数 | **9.0K** |
| 上海薪资中位数 | **11.0K** |
| “业务分析”溢价 | +1.9K（+17.6%，n=13 vs 17） |

## 三个结论

1. **门槛是 SQL + 沟通，不是 Python。** Python 只有一半岗位提，建模只有四成——先把 SQL 和表达练到能用，再谈建模。
2. **贵阳比上海低 2.0K（中位数），不是低一半。** 对刚入行的人，本地生活成本优势足以覆盖这个差距。
3. **“业务分析溢价 17.6%”这条我自己不信。** 20 条时算出来是 **−6.8%**，补到 32 条翻成 +17.6%。样本一动结论就翻转，说明它是噪声，不能当结论用——**这条恰好是“小样本不可靠”的活教材**。

## 局限（必须写，评委会问）

- **样本小**：32 条，非随机抽样，不代表全量岗位。
- **平台偏差**：BOSS 直聘禁止复制、应届生求职网岗位名不在正文区，**实际只稳定采到两家**。
- **单时点**：只反映采集当天的在招要求，不反映趋势。
- **技能识别靠词典**：同义表述可能漏检（如“取数”未命中 SQL）。
- **薪资取区间中值**：区间宽窄不一，会平滑掉极端值。

## 目录

```
pipeline/
├─ raw/                 原始文本（每个文件 = 一个平台 × 一个城市）
├─ data/                jobs.csv、jobs.db
├─ charts/              图表数据 CSV + 出图 PNG
├─ 01_build_db.py       解析、清洗、过滤、去重、入库（仅标准库）
├─ 02_queries.sql       统计查询
├─ 03_export_charts.py  导出图表用 CSV
└─ 04_render_charts.py  Pillow 出图（不依赖 matplotlib）
```

## 怎么跑

```powershell
python 01_build_db.py        # raw/*.txt → data/jobs.csv + jobs.db
python 03_export_charts.py   # data/jobs.db → charts/*.csv
python 04_render_charts.py   # charts/*.csv → charts/*.png
```

全程不需要 pip 安装任何库。

## 我踩的坑

1. **整页复制会带进“相似职位”的技能标签**，导致所有岗位都“要求 SAS”。后来改成只取「职位描述 → 职位发布者」之间的正文。
2. **薪资有 6 种写法**：`5000-7000元`、`1.5-3万`、`6千-1万`、`8-13K·13薪`……正则改了 4 版。还踩过 `100-299人`（公司规模）被当成薪资、`1-3年`（经验）被当成薪资。
3. **同一个岗位被复制两次**，去重从“比对原文”改成“岗位名+薪资+经验+学历”指纹才有效。
4. **20 条时得出的结论，32 条就被推翻**——这是最值钱的一课。
